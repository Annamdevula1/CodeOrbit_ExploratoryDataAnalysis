# Exploratory Data Analysis (EDA)

# Project title:
Exploratory Data Analysis (EDA).

# Dataset Used:
Iris Dataset

## Project Overview
This project performs Exploratory Data Analysis (EDA) on the Iris flower dataset to understand the patterns, relationships, and characteristics of different flower species.

## Dataset Information
The Iris dataset contains 150 flower samples with 5 columns:

- sepal_length
- sepal_width
- petal_length
- petal_width
- species

The dataset contains three species:
- Iris-setosa
- Iris-versicolor
- Iris-virginica

## Tools and Libraries Used

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Setup Instructions

Install the required Python libraries.
Open Google Colab or Jupyter Notebook.
Upload the Iris dataset (iris.csv).
Import the required libraries (Pandas, NumPy, Matplotlib, and Seaborn).
Load the dataset into a DataFrame.
Check the dataset structure and information.
Perform data cleaning and check for missing values.
Generate descriptive statistics.
Create EDA visualizations.
Analyze patterns, relationships, and outliers.
Run all notebook cells to reproduce the analysis results.
